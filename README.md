Solmar Nights is an original open-world crime game set in the sun-soaked city of Solmar Bay: steal cars, outrun the SBPD, and run five story missions for Vera Solano. It runs entirely in the browser with no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Controls: WASD move/drive, E enter and exit cars, mouse aim and click to shoot, F punch, N start a mission, T taxi fare, R rampage, P pause, H save, L load.
